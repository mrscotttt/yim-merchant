This is a [Next.js](https://nextjs.org)
ui : tailwind css
main storage : localStorage (React Context)

## Getting Started

First, run the development server:


```bash
npm install
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open homepage [http://localhost:3000](http://localhost:3000)
